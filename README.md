# AnakhOn — installers and updates

**AnakhOn — Precision On**

AnakhOn is a plugin for AutoCAD 2021–2026 for curtain wall engineers.

## Download

**Package Kostika — newest installer:**
https://github.com/Bordiuh-yurii/anakhon-releases/releases/download/kostika-latest/AnakhOn-Kostika-setup.exe

All versions: https://github.com/Bordiuh-yurii/anakhon-releases/releases

## Install

1. Close AutoCAD.
2. Run the installer. Windows may warn that the publisher is unknown — click **More info → Run anyway**.
3. Start AutoCAD. The License window opens: press **Copy** and send the computer code to your AnakhOn administrator.
4. When you receive the license key, copy it and press **Paste key**.

## Updates

AnakhOn checks for a new version once a day when AutoCAD starts, and offers to install it.
You can also check yourself: **Settings → General → Check for updates**.
Your license, your own catalog elements and your settings stay as they are.
